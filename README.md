Сделал программу для проводных и радиоканалов. Она читает данные из файла, хранит их в срезе и выводит на экран и в файл

Исходные файлы: `channel.go` - 448 байт; `container.go` - 149 байт; `input.go` - 2783 байта; `main.go` - 937 байт; `output.go` - 909 байт. Всего 5 файлов, 5226 байт. Файл с интерфейсом - 1, остальные - 4. В программе 6 типов и 10 функций и методов.

Зависимости: `main.go` использует `input.go` и `output.go`; они используют `channel.go` и `container.go`; `container.go` использует `channel.go`.

Проверил пять наборов: 0, 1, 2, 5 и 11 каналов. Количество и порядок верны; вывод на экран и в файл совпадает.
